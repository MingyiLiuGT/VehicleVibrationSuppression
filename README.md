# Vehicle Vibration Suppression

Simulation code, trained neural controllers, and experiment data for vehicle suspension vibration suppression using preview model predictive control (MPC) and mass-conditioned neural control.

The quarter-car model includes sprung and unsprung dynamics. The standard configuration uses a 10 ms sampling period, a 30-step prediction horizon, and a ±500 N actuator force limit. Online mass adaptation estimates sprung mass and supplies it to a frozen neural controller. Separate studies compare fixed, estimated, and true mass inputs to MPC, including an ±800 N actuator experiment.

## Installation

Python 3.12 was used for the recorded experiments. Install the pinned dependencies in a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Run commands from the repository root. The repository contains the contents of the local `code` directory; no manuscript, Word files, or parent project directory is required. Local environments and caches are excluded from version control.

## Reproduce and verify

```bash
python reproduce.py check     # Check models, saved trajectories, metrics and timing records
python reproduce.py figures   # Regenerate numerical figures from saved results
python reproduce.py mass      # Replay mass adaptation studies
python reproduce.py road      # Recompute measured-road and half-car experiments
```

`check` does not retrain models or rerun timing benchmarks. It writes numerical validation reports. Existing mass trajectories are reused only when the corresponding protocol checks allow it. To force a full recomputation, move the relevant trace directory aside in a separate working copy first. Analytical schematic figures are not generated by this repository.

## Training

Use a separate working copy when retraining so new weights are not mixed with existing trajectories.

```bash
python run_experiments.py --stage all
python train_paired_mass.py
python train_mass_heads.py
python evaluate_paired_mass.py --name mass_heads_dense --split development
python tune_mass_estimator.py
python freeze_mass_models.py
```

The paired training set uses masses of 200, 240, 270, 300, 330, 360, 420 and 450 kg. The final refined controller additionally uses synthetic low-amplitude road coverage and a height-invariant input transformation:

```bash
python refine_road_coverage.py --stage dataset
python refine_road_coverage.py --centered --stage train
```

This refinement starts from the saved `results/road_coverage/initial_policy.npz`, not the updated final policy. Training and checkpoint selection use synthetic roads. The 48 additional training roads and 12 validation roads cover 0.15–8 Hz, 1–15 mm RMS and ±30 mm height offsets. The deployed weights are in `results/mass_optimization/mass_heads_final/policy.npz`; the matching refined candidate and training records are in `results/road_coverage_centered/`.

## Mass experiments

The broad mass study runs for 24 s, with mass changes at 4 s and 20 s. Its primary evaluation window is 4–20 s. RLS updates use the preceding sample's applied force and measured acceleration; the controller receives no true change-time signal. The tuned estimator uses forgetting factor 0.97, update gate 0.02 and mass bounds 180–480 kg.

The focused study separately defines excitation ranges using development cases, then evaluates fresh roads:

```bash
python mass_regime_study.py verify
python mass_regime_study.py mass
python mass_regime_study.py excitation
python mass_regime_study.py neighborhood
python mass_regime_study.py validation
python mass_regime_study.py mpc
python mass_regime_study.py audit
python mass_regime_study.py figures
```

The decrease range is 19–21 mm and 1.3–1.5 Hz; the increase range is 24–26 mm and 0.6–0.8 Hz. Each uses 24 fresh roads. Results apply to these declared ranges and do not replace the broad-distribution results. Protocols, all development results, and all 720 validation trajectories are retained in `results/mass_regime_study/`.

Additional MPC-only comparisons:

```bash
python evaluate_adaptive_mass_mpc.py
python evaluate_adaptive_mass_mpc_800.py
python evaluate_constant400_mpc.py
```

The ±800 N experiment changes only the force constraint, keeping the physical effort penalty unchanged. The constant-mass experiment uses a 400 kg plant throughout and compares prediction models of 300 and 400 kg at ±500 N. These are separate studies, not substitutes for the main neural-control validation. Individual reports explain the observed benefits and limitations.

## Measured road and half-car experiments

Measured inputs are derived from the P79 Laser 21 right-wheelpath elevations in the DTU LiRA-CD reference dataset. Attribution, license, original source information and checksums are preserved in `results/road_halfcar/source/provenance.json` and the road-coverage provenance files. See [DATA_SOURCES.md](DATA_SOURCES.md).

The measured-road study uses three nonoverlapping intervals of the same wheelpath. The first two were inspected during regression analysis; the third was evaluated after the final weights were frozen. These are not three independent physical routes. No measured-road samples enter neural training or normalization. All segment outcomes are retained.

```bash
python validate_road_halfcar.py --check
python evaluate_road_coverage.py --name road_coverage_centered --source-start 2000
python check_road_coverage.py
python check_road_coverage_regression.py
```

The saved road inputs support local reproduction. To rebuild additional intervals from the full source CSV, pass `--source /path/to/m13_zp_vh.csv` to `evaluate_road_coverage.py`; the source MD5 is checked. Half-car experiments evaluate preview MPC with heave, pitch and front/rear wheel dynamics; they do not evaluate half-car neural control or online mass estimation.

## Timing and figures

```bash
python benchmark_optimized_mass.py --disable-gc
python analyze_optimized_mass.py --timing-only
python analyze_results.py --figure2-only
```

Timing results are software latency measurements on Apple M4 using float64, requested single-thread execution, 100 warm-up calls and 5,000 recorded calls per path. They exclude sensing, communication and physical actuation. All samples are retained. Rebenchmarking overwrites the timing outputs; use a separate working copy to preserve published measurements.

Numerical plots are stored in `results/figures/`, `results/mass_optimization/figures/`, and individual study directories. Reports describe selection rules and evaluation windows. Mass tracking is reported through time histories and windowed estimation errors, not an undefined convergence time.
