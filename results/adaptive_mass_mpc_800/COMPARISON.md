# 800 N 与 500 N 的 MPC 质量适应对比

三种 MPC 均重新运行，共 96 个工况、288 条轨迹。只将控制力约束从 ±500 N 改为 ±800 N；代价函数中的力归一化仍为 500 N，因此物理控制力惩罚不变。道路、质量变化、噪声、RLS 参数和评价窗口不变。

下表为质量变化后 4–20 s 的平均加速度 RMS 相对各自固定质量 MPC 的降低百分比；负值表示退化。

| 道路 | 质量 kg | 500 N 在线辨识 | 800 N 在线辨识 | 800 N 真实质量 |
|---|---:|---:|---:|---:|
| 正弦 | 200 | 6.63% | 0.00% | 36.75% |
| 正弦 | 240 | 2.17% | 0.00% | 21.54% |
| 正弦 | 360 | −0.77% | 0.00% | −19.55% |
| 正弦 | 420 | −0.98% | 0.00% | −37.81% |
| 多正弦 | 200 | −0.28% | −1.78% | −1.69% |
| 多正弦 | 240 | −0.37% | −1.07% | −1.23% |
| 多正弦 | 360 | 0.35% | 2.50% | 2.09% |
| 多正弦 | 420 | 0.71% | 5.28% | 4.41% |

## 辨识更新核查

RLS 回归量为 phi = [−ks(zs−zu)−cs(vs−vu)+u]/300，仅在 |phi| >= 0.02 时更新。800 N 下，48 条正弦道路自适应轨迹的全部 115,200 个采样点均未达到阈值，最大 |phi| 为 0.0151876054，估计质量全程为 300 kg。对应在线辨识控制器实际退化为固定质量控制器，不能将正弦工况称为成功辨识。

多正弦道路共有 24,088/115,200 个采样点达到更新阈值。360/420 kg 的末段平均质量相对误差为 6.31%/6.26%，分别有 9/12 和 10/12 条道路加速度 RMS 改善。

## 物理解释

放宽限幅显著降低了振动和饱和比例，也削弱了可用于质量辨识的激励。200 kg 正弦工况固定质量 MPC 的 RMS 从 500 N 时的 0.121645 降至 800 N 时的 0.006436 m/s²；800 N 真实质量 MPC 可进一步降至 0.004071 m/s²，但现有辨识器不能获得这部分收益。相对百分比需结合较小的绝对加速度理解。

真实质量输入并非加速度单项指标的性能上界：MPC 同时优化行程、轮胎动载荷和控制力，且采用有限预测时域。在线辨识偶尔优于真实质量参考，也不代表质量估计优于真实值。

核验通过：动力学递推最大残差 4.44e−16，控制力均满足 ±800 N 约束，估计均按上一采样观测更新。原 500 N 实验、论文和回复信未修改。
